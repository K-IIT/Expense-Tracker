 Expense Tracker

Автор: Чернаков Павел Алексеевич 
Описание: Простое приложение для учёта личных расходов с фильтрацией и экспортом в JSON.
Технологии: Python 3.x + Tkinter + JSON + Git.
Лицензия: MIT.
Как использовать?
Установите Python 3.x.
Клонируйте репозиторий: git clone https://github.com/ivanov/expense_tracker.git
Запустите: python expense_tracker.py
Добавляйте расходы через форму.
Используйте фильтры и подсчёт суммы.
Сохраняйте/загружайте данные через JSON.
Копировать
 Примеры использования:
- Добавить расход: сумма — 1200.50 ₽; категория — еда; дата — 2026-04-22.
- Фильтровать по категории «еда».
- Посчитать сумму расходов с 2026-04-01 по 2026-04-30.
Возможные тесты:
Ввод отрицательной суммы — ошибка.
Ввод даты не по формату — ошибка.
Фильтрация по несуществующей категории — пустой результат.

## Как запустить программу

### 1. Установка Python и зависимостей
*   **Python:** Убедитесь, что у вас установлен Python версии 3.8 или новее.
*   **Зависимости:** Установите библиотеку для календаря:
    ```bash
    pip install -r requirements.txt
    ```
*   *Проверка установки:* Откройте терминал и введите `python --version` или `python3 --version`.

### 2. Запуск приложения

**Вариант А: Из исходного кода**
1.  Клонируйте репозиторий на свой компьютер:
    ```bash
    git clone <ссылка_на_репозиторий>
    cd expense_tracker
    ```
2.  Установите зависимости (если вы еще этого не сделали):
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите скрипт из папки проекта:
    ```bash
    python expense_tracker.py
    # или для некоторых систем:
    python3 expense_tracker.py
    ```
4.  Окно приложения должно появиться на экране.
