 Expense Tracker

Автор: Чернаков Павел Алексеевич 
Описание: Простое приложение для учёта личных расходов с фильтрацией и экспортом в JSON.
Технологии: Python 3.x + Tkinter + JSON + Git.
Лицензия: MIT.
Как использовать?
Установите Python 3.x.
Клонируйте репозиторий: git clone https://github.com/ivanov/expense_tracker.git
Запустите: python expense_tracker.py
Добавляйте расходы через форму.
Используйте фильтры и подсчёт суммы.
Сохраняйте/загружайте данные через JSON.
Копировать
 Примеры использования:
- Добавить расход: сумма — 1200.50 ₽; категория — еда; дата — 2026-04-22.
- Фильтровать по категории «еда».
- Посчитать сумму расходов с 2026-04-01 по 2026-04-30.
Возможные тесты:
Ввод отрицательной суммы — ошибка.
Ввод даты не по формату — ошибка.
Фильтрация по несуществующей категории — пустой результат.
